# ADR 001 - Escolha das tecnologias

## Status

Aceito

## Contexto

No início do projeto foi necessário definir quais tecnologias seriam utilizadas para desenvolver e organizar o sistema de empréstimo de livros.

## Decisão

A linguagem Python foi escolhida para o desenvolvimento da aplicação.

O GitHub será utilizado para controle de versão do código, organização das tarefas e revisão das alterações.

O Docker será utilizado para facilitar a configuração do ambiente e a execução da aplicação.

## Motivo da escolha

As tecnologias escolhidas são adequadas ao projeto e facilitam o desenvolvimento, a organização do código e a execução do sistema em diferentes ambientes.

## Consequências

A equipe deverá manter o código organizado no GitHub e utilizar o fluxo de branches e Pull Requests definido no projeto.
