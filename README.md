# Sistema de Empréstimo de Livros de Biblioteca

## 📚 Visão Geral
Esta API foi desenvolvida para o controle automatizado de acervo e gerenciamento de empréstimos de materiais bibliográficos voltados para estudantes. O sistema visa otimizar a rotina de circulação de livros, garantindo agilidade no atendimento, precisão no controle de prazos e transparência nas políticas da biblioteca acadêmica.

## ⚙️ Regras de Funcionamento

O fluxo operacional e as diretrizes que regem a circulação de materiais no sistema compreendem os seguintes parâmetros:

- **Limite de Empréstimos:** Cada estudante pode manter sob sua responsabilidade um limite máximo de **3 livros simultâneos**.
- **Prazo de Devolução:** O prazo fixo padrão estabelecido para a devolução dos exemplares emprestados é de **7 dias**.
- **Política de Atrasos:** O sistema realiza o cálculo de uma multa fixa aplicada por dia de atraso caso a devolução ultrapasse o prazo estipulado.
- **Controle de Pendências:** Estudantes que possuятся pendências ativas no sistema sofrem bloqueio automático para a realização de novos empréstimos até a devida regularização.
