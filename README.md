# Sistema de Empréstimo de Livros - Biblioteca

## Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema para auxiliar no controle de empréstimos de livros de uma biblioteca.

O sistema será utilizado para organizar informações sobre alunos, livros e empréstimos, além de controlar devoluções e possíveis multas.

## Funcionalidades previstas

Durante o desenvolvimento, o sistema deverá contar com funcionalidades para:

- cadastrar alunos;
- cadastrar livros;
- realizar empréstimos;
- registrar devoluções;
- verificar o limite de empréstimos;
- calcular multas quando necessário;
- realizar testes das funcionalidades.

## Tecnologias utilizadas

O projeto será desenvolvido utilizando Python.

O GitHub será utilizado para armazenar e controlar as versões do código e também para organizar as tarefas da equipe.

O Docker será utilizado para facilitar a configuração e execução do projeto.

## Como executar o projeto

As instruções completas para instalar as dependências e executar o sistema serão adicionadas conforme o desenvolvimento do projeto avançar.

## Organização do desenvolvimento

Para manter o projeto organizado, cada nova funcionalidade deverá ser desenvolvida em uma branch própria.

As branches de funcionalidade seguem o padrão `feature/`.

Por exemplo:

- `feature/alunos`
- `feature/livros`
- `feature/emprestimos`
- `feature/testes`
- `feature/docker`
- `feature/documentacao`

A branch `develop` será utilizada para integrar as funcionalidades desenvolvidas pela equipe.

A branch `main` representa a versão principal do projeto e permanece protegida contra alterações diretas.

Toda alteração deverá passar por um Pull Request e ser revisada antes de ser integrada.

## Documentação técnica

As decisões técnicas importantes do projeto serão registradas na documentação de ADR.

Esses registros serão utilizados para explicar decisões como escolha de linguagem, banco de dados, arquitetura e outras tecnologias utilizadas no desenvolvimento.
